The cat app that used 12% of the CPU doing nothing

My cat app once used 12% of the CPU while doing nothing.

It is called Cataholic. It puts a chunky cat on your Mac. When the cat is just sitting there, the app has no work to do.

But 12% of the CPU was gone anyway. The machine was busy being busy.

"No theatrics," I said. Now it uses almost none.

If something is idle, it should be idle.

A process that looks active while producing nothing costs something, and the cost is easy to miss because nothing visibly breaks. It is a good check on a finished thing: does it do work when there is work, and rest when there is none? The cat passes now.
