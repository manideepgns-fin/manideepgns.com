How I work

I write down the real problem before I fix anything.

  1. Look for the real problem first.

    Month-end numbers took fifteen days. The reporting wasn't the problem: the data lived in ten places. I wrote that down before fixing anything.

    Read the memo →
  2. One rule beats four exceptions.

    Billing in India, the UK, the Middle East and the US now runs on the same rules. Fewer special cases means fewer things that fail quietly.

  3. Say what went wrong.

    After my first Big-4 audit, I analysed all 1,967 emails to see why it nearly slipped. It wasn't effort, it was timing. So the hard calls moved from December to July.

  4. If it's idle, it's idle.

    My cat app once used 12% of the CPU while doing nothing. "No theatrics," I said. Now it uses almost none.
